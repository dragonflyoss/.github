# .github

This repository provides default community files for all repositories in the dragonflyoss organization. It helps set up things like issue templates, pull request templates, CODEOWNERS, CONTRIBUTING, SECURITY, and FUNDING files for the whole organization.

## Structure

- `profile/`: Organization-level community files (like the profile README).
- Other files (such as ISSUE_TEMPLATE, PULL_REQUEST_TEMPLATE, CODEOWNERS, etc.) can be placed in the root directory.

## Main Purpose

- Manage and maintain community guidelines and templates for all repositories in the organization.
- Apply default community settings to new repositories automatically.
- Make it easier for community members to contribute.
